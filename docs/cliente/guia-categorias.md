# Rey Festas · Qual categoria usar

Guia de lançamento no Control ERP para a equipe financeira. Use sempre a categoria com o código completo (ex.: 30.01.04). Os títulos (10, 30, 30.01...) não recebem lançamento.

## Regras que mais confundem

| Situação | Categoria |
| --- | --- |
| Compra de peça para **aumentar** o acervo (mais cadeiras, toalhas novas) | 70.02.01 Compra de acervo para locação |
| Compra de peça para **repor** uma que quebrou ou sumiu | 30.01.04 Reposição de peças perdidas/quebradas |
| Frete, diária extra, higienização, avaria ou multa **cobrados do cliente** | Na receita do contrato: 10.01 Locação ou 10.02 Serviços e Buffet |
| Contrato com desconto | Receita pelo valor cheio e o desconto em 20.02.02 |
| Parcela de empréstimo | Valor principal em 70.03.01 e juros em 50.03.03 |
| Retirada dos sócios além do pró-labore | 90.01.01 Distribuição de lucros aos sócios |
| Transferência entre contas da própria empresa | Entrada 60.01.04 e saída 70.01.02 (não entra no DRE) |
